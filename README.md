# Network

Учебный HTTP-сервер на TypeScript и встроенном модуле `node:http`. Без фреймворков и базы данных: новый пользователь возвращается в ответе, но между запросами не сохраняется.

## Запуск и тесты

Нужен Node.js 20 или новее.

```sh
npm install
npm start
npm test
```

Сервер слушает порт `3000`; значение можно переопределить через переменную окружения `PORT`.

## `GET /search?q=node`

- `200 OK` — `{ "q": "node" }`, если `q` передан и не пуст (пробелы по краям сохраняются).
- `400 Bad Request` — `{ "error": "..." }`, если параметр отсутствует, пуст или состоит из пробелов.
- `404 Not Found` — `{ "error": "Not Found" }` для неизвестного пути.
- `405 Method Not Allowed` — `{ "error": "Method Not Allowed" }` и `Allow: GET`, если для `/search` использован другой метод.

## `POST /users`

Передайте JSON с непустым строковым `name` и целым неотрицательным `age`:

```http
POST /users
Content-Type: application/json

{ "name": "Anna", "age": 25, "note": "это поле будет проигнорировано" }
```

- `201 Created` — `{ "name": "Anna", "age": 25 }`. Лишние поля не возвращаются.
- `400 Bad Request` — тело не является корректным JSON-объектом или обязательные поля имеют неверный формат.
- `404 Not Found` — неизвестный путь.
- `405 Method Not Allowed` — другой метод для `/users`; ответ содержит `Allow: POST`.
- `413 Payload Too Large` — тело больше 1 МиБ. Если `Content-Length` выше лимита, ответ отправляется до чтения тела; для передачи без этого заголовка размер ограничивается по мере чтения.
- `415 Unsupported Media Type` — `Content-Type` не `application/json`.

Все ошибки возвращаются JSON-объектом вида `{ "error": "..." }`. Проверки формата вынесены в unit-тесты, HTTP-ответы проверяются интеграционными тестами; обе группы запускаются командой `npm test`.
